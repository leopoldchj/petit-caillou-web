# Petit Caillou Web

The Petit Caillou web application, built with React, TypeScript, Vite, and
Mantine.

## Install

```bash
npm install
```

## Development

```bash
npm run dev
```

The server starts at `http://localhost:5173`.

## Quality checks

```bash
npm run lint
npm run build
```

These commands are also available from the shared repository root.

## Component library

[Mantine](https://mantine.dev/) provides the shared components, design tokens,
and application theme. Project-specific CSS is reserved for the visual identity
and custom motion.
